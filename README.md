# Pushrank Claude plugin

Official [Pushrank](https://pushrank.io) plugin for Claude: it connects Claude to your Pushrank account
through the Pushrank MCP server and adds skills for SEO reviews, article generation, publishing, keyword
management, and project setup.

The plugin lives in [`plugins/pushrank`](plugins/pushrank); see its README for details.

## Install

- **claude.ai / Claude desktop**: Customize > Plugins > Add > Add marketplace, then enter
  `peak-lab/pushrank-claude-plugin`.
- **Claude Code**: `/plugin install pushrank --marketplace peak-lab/pushrank-claude-plugin`
